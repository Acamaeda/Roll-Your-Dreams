# Events

The Event system lets you do a lot of more in-depth things that would normally require code, without code.
They're all about making things happen under certain conditions. There are three main parts:
	- Triggers: What causes an Event to start, when a Trigger triggers, it goes through all of its children one by one to run them.
	- Actions: When a Trigger runs them, they do something, it can be dialogue, changing something about the player, or more.
	- Conditions: When a Trigger runs them, they check their condition, and if it's met, it will run all of its children.
		(Many Conditions can also be used as Triggers)
		
There are also Counters, which can keep track of a number value, and Timers, which are Counters that change over time.
