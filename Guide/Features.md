# Features

Features are nodes that you can attach to other things to change them or make
them do different things. There are a variety with different effects.

There are two main types of Feature. Solo Features affect one object, and you
put it as a child of the object. Group Features affect multiple objects, put as
children of the Feature. Some Features can work as either. There are also Player
Features, which can only go on the Player.

Once you add a feature to the object, you can configure its properties in the right-side panel.

## List of Features:
	
	Solo:
		- [Rollable Properties](Features/RollableProperties.md): Change some basic features of Rollables (Rollables only)
		- [Spin](Features/Spin.md): Makes the object spin around.
		- [Recolor](Features/Recolor.md): Changes the color of the object.
		- [Recolor](Features/Resize.md): Changes the size of the object.

	Group:
		- [Orbit](Features/Orbit.md): Makes objects move in a circle around a center point.
